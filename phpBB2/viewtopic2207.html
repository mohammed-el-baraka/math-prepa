Voici ma solution pour inclure des équations dans un forum phpBB2 sans disposer de serveur mais en prenant appui sur un serveur spip avec mise en cache des images png obtenues.


dans include/bbcode.php, à la fin de la fonction secondpass j'ajoute :
Code:

preg_match_all('/\[tex\]((?s).*?)\[\/tex\]/ie',$text,$out,PREG_PATTERN_ORDER);
 for ($i_out=0;$i_out<count($out[1]);$i_out++) mathpng(db($out[1][$i_out]));
$text = preg_replace('/\[tex\]((?s).*?)\[\/tex\]/ie',"'<img src=\"cachetex/'.md5(trim(math_ignore_dangerous(db('$1')))).'.png\" style=\"vertical-align:middle\" />'", $text);

et ailleurs dans cette page la fonction
Code:

function db($texte)
{
$texte=preg_replace('[&amp;]','&',$texte);
$texte=preg_replace('[\n]',' ',$texte);
$texte=preg_replace('[\r]',' ',$texte);
return $texte;
}



dans include/functions.php, j'ajoute :
Code:

function math_ignore_dangerous($texte)
{
$danger = "include|def|command|loop|repeat|open|toks|".
"output|input|catcode|name|\^\^|every|errhelp|".
"errorstopmode|scrollmode|nonstopmode|batchmode|read|".
"write|csname|newhelp|uppercase|lowercase|relax|".
"aftergroup|afterassignment|expandafter|noexpand|".
"special";
if (ereg("($danger)",$texte,$regs)) return "\\textrm{\color{red}Don't ``$regs[1]'' me.}";
return $texte;
}
function math_enhance($texte)
{
$texte=str_replace("\t","\\t",$texte);
$texte=str_replace("\n","\\n",$texte);
$texte=str_replace("\r","\\r",$texte);

$tex = "\\setbox1=\\hbox{\$\\displaystyle ".$texte."\$}\n"
                ."\\newdimen\\haut\n\\newdimen\prof\n"
                ."\\haut=\\ht1\n\\prof=\\dp1\n"
                ."\\ifdim\\haut>\\prof\\prof=\\haut\\else\\haut=\\prof\\fi\n"
                ."\\color{white}\\vrule height \\haut depth \\prof width 0.1pt\\color{black}\\box1";
return $texte;
}

Ces deux premières fonctions sont des classiques trouvées sur le net
J'ajoute encore
Code:

function mathpng($texte)
{
$texte = math_ignore_dangerous($texte);
$fichier = "cachetex/".md5(trim($texte)).".png";
if (!file_exists($fichier))
{
$texte = urlencode(math_enhance($texte));
$image=imagecreatefrompng("http://math.spip.org/tex.php?".trim($texte));
$x=imagesx($image);$y=imagesy($image);
$image2=imagecreate($x+10,$y+10);
if (imagecopy($image2,$image,5,1,1,1,$x-1,$y-1))
{
imagecolortransparent($image2,imagecolorat($image2,0,0));
imagepng($image2,$fichier,9); 
}
imagedestroy($image);
imagedestroy($image2);   
}
return($fichier);
}

Cette fonction met l'image en cache et la décale quelque peu pour améliorer la ligne de base même si ce n'est pas parfait
Il ne reste plus qu'à créer le répertoire cachetex à la racine de phpBB2.

Pour finir, on ajoute le BBcode Tex. Ceci m'a été possible grâce au lien :
http://www.phpbb.com/community/viewtopic.php?t=94454
Dans la portion "Secondly", il est décrit la démarche à suivre (bien que si mes souvenirs sont bons celle-ci n'est pas entièrement complète).
